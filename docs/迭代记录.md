## V5.0 — 新增「游戏」Tab（弹球击退星球）(2026-08-10)

### 新需求（V4 → V5）
用户要求在第 4 个 Tab 实现一款动作小游戏，核心为「弹球击退下压星球」玩法。

### 设计要点（需求拆解）
1. **屏幕适配**：保持竖屏，以 Samsung Galaxy S23 Ultra（19.3:9）为基准，布局分三层——顶部敌方压迫区 / 中部弹球战场 / 底部球网控制区。
2. **核心玩法**：顶部不断生成并下压星球，速度/密度随关卡递增；底部球网由玩家滑动控制；能量球在边界与球网间反弹，击中星球将其击退/粉碎。
3. **视觉特效**：命中触发粒子爆炸 + 光晕脉冲 + 震屏；星球被消灭有碎裂特效；危险预警时屏幕边缘红光闪烁；动态深空背景（星尘流动 + 霓虹光）。
4. **技术选型**：复用现有 Canvas 2D 技术栈（与 PK/探索一致），requestAnimationFrame + delta time 实现帧率无关的物理（兼容 60/120fps），圆-圆与圆-AABB 碰撞检测。

### 实现措施（本次交付：入口架构 + 基础 UI + 核心碰撞原型）
- **入口架构**：主菜单新增「游戏」按钮；`index.html` 新增 `#arcade-screen`；`js/game.js` 新增 `startArcade()` 并在 `hideAll()` 中停止游戏循环。
- **独立模块**：新增 `js/arcade.js`，以 `window.ArcadeGame = { init, start, stop }` 暴露，与 `game.js` 解耦。
- **基础 UI 框架**：顶部 HUD（关卡/分数/生命）、顶部压迫提示条、战场 canvas（DPR 自适应）、底部控制提示、游戏内结算面板。
- **核心碰撞原型**：
  - 挡板：指针/触摸滑动控制（移动端 `touch-action:none` + `preventDefault`）
  - 能量球：边界反弹 + 挡板反弹（由击打点决定反弹倾角）
  - 星球下压：生成于顶部，向下漂移，速度/密度/血量随关卡（每 30s）递增
  - 球-星球碰撞：圆-圆判定，命中后星球被击退（向上冲量）并扣血，血量归零则碎裂消除并得分
  - 生命机制：能量球掉落或星球触底各扣 1 生命，3 条生命用尽则游戏结束
- **特效**：粒子爆炸（`burst`）、命中光晕脉冲（`planet.flash`）、震屏（`shake` 平移画布）、危险红光（`arcade-danger` 透明度随 `danger`）、动态星尘背景。

### 变更文件清单

- `css/style.css` — 新增 `.arcade-*` 全部样式（响应式竖屏布局 + 危险红光 + 结算面板）

## V5.1 — 游戏 Tab 音效（Web Audio 合成）(2026-08-10)

### 需求
在 V5 游戏 Tab 基础上补充音效：命中/粉碎/挡板反弹/失命/过关/结束/开始。

### 技术方案
采用 **Web Audio API 实时合成**，**不引入任何音频文件**（无需打包资源、离线可用、在 Android WebView 中可直接播放）。
- 新增 `js/arcade.js` 内 `Sfx` 模块（IIFE 私有 `actx`），提供 `hit / destroy / paddle / lifeLost / levelUp / gameOver / start / unlock / toggleMute / isMuted`。
- `tone()` 用 OscillatorNode（正弦/方波/三角/锯齿）+ GainNode 包络合成；`destroy` 叠加 BufferSource 白噪声（lowpass 滤波）模拟爆炸。
- 移动端自动播放策略：在 `pointerdown` 与 `start()` 中调用 `Sfx.unlock()` 解锁 AudioContext；首次交互后才出声。

### 触发点
- 球命中星球（未粉碎）→ `Sfx.hit()`；粉碎 → `Sfx.destroy()`
- 挡板接球 → `Sfx.paddle()`
- 失命 → `Sfx.lifeLost()`
- 过关（每 30s）→ `Sfx.levelUp()`
- 游戏结束 → `Sfx.gameOver()`；开局 → `Sfx.start()`

### 变更文件
- `js/arcade.js` — 新增 `Sfx` 模块，并在上述事件点调用；`init()` 绑定静音按钮
- `index.html` — HUD 新增 `arcade-mute` 静音开关按钮
- `css/style.css` — 新增 `.arcade-mute` 圆形按钮样式
- `ARCHITECTURE.md` — 第 5 节补充音效说明 + 修改指南 + V5.1 版本历史
- `docs/迭代记录.md` — 本章节
- `planet-pk.apk` — 重新构建（9.6MB）

### 遗留问题（更新）
- 游戏音效仅覆盖关键动作，仍可加：背景循环音乐、连击音、星球触底专属音
- PK / 探索 / 我的星系三个 Tab 暂未加音效（如需统一音效体验可后续扩展）

## V6.0 — 游戏 Tab 重写：太空射击模式 (2026-08-11)

### 问题
V5 弹球击退星球原型在手机上渲染异常（canvas 空白，只有背景星尘可见），且弹球玩法对手机用户不够直观。

### 需求
用户要求改为**太空飞机射击游戏**：
- 飞机不断往前飞（竖屏视角下 = 向上射击）
- 触摸滑动控制前后左右飞行（4 方向自由移动）
- 星球从上方落下作为障碍物/敌人
- 参考经典桌面街机太空射击游戏

### 技术方案
完全重写 `js/arcade.js`，从 breakout 弹球 → **space shooter**：

**核心实体**
| 实体 | 说明 |
|------|------|
| Ship（战机） | 三角形飞船 + 引擎尾焰动画，触摸拖动 4 方向移动（lerp 平滑跟随） |
| Bullet（子弹） | 自动向上发射（0.22s 间隔），发光能量弹 |
| Planet（天体） | 从 data.js CELESTIAL_DATA 取真实天体，从顶部下落 |
| Particle（粒子） | 命中爆炸、失命爆裂 |

**玩法机制**
- 战机在屏幕下半区自由移动（手指跟哪飞哪）
- 自动连发子弹向上射击
- 子弹命中天体 → 扣血/粉碎得分（圆-圆碰撞）
- 天体撞到战机 → 扣命 + 天体消失
- 天体穿过屏幕底部 → 扣命
- 每 30 秒一关，速度/密度/血量递增

**保留内容**
- Sfx 音效模块（shoot/hit/destroy/lifeLost/levelUp/gameOver/start）
- 粒子爆炸系统
- 震屏效果
- 危险红光预警
- 动态星空背景
- 静音开关
- 真实天体数据 + 图片复用 PKImageCache

**关键修复（解决空白问题）**
- 战机半径加大到 `W * 5.5%`（24~42px），确保手机上清晰可见
- 初始天体直接生成在屏幕可见区域（`H * 3%~38%`），不再等飘入
- 子弹半径 `W * 1.2%`（4~7px）+ 3x 发光晕圈，视觉明显
- 第 10 帧强制 resize（防首次布局延迟）

### 变更文件
- `js/arcade.js` — **完全重写** 为 space shooter 模式
- `index.html` — 底部提示文案更新为「触摸滑动控制战机飞行」
- `planet-pk.apk` — 重新构建（9.6MB）
